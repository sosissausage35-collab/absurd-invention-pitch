A program that writes one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: a doormat that sighs, rolls itself up, and refuses visitors until someone apologises for tracking mud in. It holds a small field of original pitches, ranks them lexicographically on the judge's own criteria in the judge's own order (funny invention, then clever fix, then original idea, then tight sentence — no weighted sum), and writes the winner to `/output/entry.txt`.

## Run it

```sh
npm start
```
